# RMAST Sales Funnel

An automated sales engine and growth pipeline built with Next.js 16, React 19, MongoDB, and Gemini AI.

## Project Structure

- **[`rmast-sales-engine/`](./rmast-sales-engine)**: Next.js application containing the sales funnel, CRM dashboard, lead discovery, enrichment, outreach automation, and appointment scheduling.

## Getting Started

Navigate to the sales engine directory and start the application:

```bash
cd rmast-sales-engine
npm install
cp .env.example .env.local
npm run dev
```

For full setup instructions, environment variable specifications, and features, refer to [rmast-sales-engine/README.md](./rmast-sales-engine/README.md).
